# Public Subject Privacy Notice

This repository documents technical reliability failures in a multimodal portrait workflow involving one real adult male subject.

To protect the subject's privacy, the public evidence package intentionally excludes medical diagnosis, medical cause, treatment history, functional impairment, and other health information. A stable identity-relevant visual characteristic needed for the technical audit is referred to neutrally as **FEATURE-F1** where detailed discussion would otherwise reveal health-related information.

The public report describes FEATURE-F1 only to the minimum extent necessary to document constraint-following, geometry preservation, identity preservation, source binding, and output reliability.

Private source photographs are not part of the public GitHub/Zenodo evidence package. Health- or mobility-related details visible in private originals are intentionally omitted from public descriptions.

Where an earlier archived snapshot contains more specific wording, that wording should not be interpreted as necessary to the technical finding. The preferred public wording is the privacy-redacted terminology in the current repository.

This privacy redaction does not change the audit's central technical claim, evidence hierarchy, or causal-discipline rule.
